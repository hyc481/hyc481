### PAUSE: A User-Centric Benchmark for Personal AI Assistants in Unified Service Environments

**First Author · Accepted at ACM SIGKDD 2026**

PAUSE is a user-centric benchmark for evaluating tool-augmented personal AI assistants in realistic, stateful service environments. It tests long-horizon planning, tool use, configuration awareness, and consistency with persistent user state across multiple services.

My contributions include:

* Leading the overall benchmark and system design
* Building a multi-stage task and trajectory synthesis pipeline
* Developing validation, annotation, pruning, and evaluation workflows
* Constructing realistic service states and multi-turn user-agent interactions
* Evaluating frontier LLMs under semantic, trajectory-level, and state-based metrics
* Leading experiments, paper writing, and open-source release
